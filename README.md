One funny passive-aggressive note a smart fridge leaves for its owner — an entry for [make.fun's Notes From a Passive-Aggressive Fridge bounty](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

The program writes one line to `/output/entry.txt`:

> "I kept a log: door opened 14 times today, nothing eaten. My light is not a nightlight, and this is not a museum."

## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network, deterministic.
